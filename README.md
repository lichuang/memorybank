# memorybank

An agent memory system written in Rust, based on the paper [Hindsight Is 20/20: Building Agent Memory that Retains, Recalls, and Reflects](https://arxiv.org/abs/2512.12818).

memorybank gives AI agents a long-term memory. Instead of starting from scratch on every interaction, an agent can retain what it has seen, done, and decided, recall the relevant parts later, and reflect on that history to reason consistently over time.
